## Организатор и игры между устройствами
Игры привязаны к идентификатору организатора в `game_settings.organizerKey`.
По умолчанию: `KonstantinD`.

На домашнем ПК можно создать игру и закрыть браузер. На рабочем ноутбуке нужно открыть игру, указать тот же идентификатор `KonstantinD` и раздел «Мои подготовленные игры» загрузит игры с сервера.

Идентификатор — не пароль и не полноценная авторизация; это ключ для поиска и группировки игр.

## Основные механики
- обычная песня и STOP;
- 2–6 команд, несколько участников;
- 🎒 Песня в мешке;
- 🔄 АПОЖ / реверс;
- ⚡ Удвоение;
- 🔨 Аукцион: старт от номинала, обязательная первая ставка открывшей команды, очередь по счёту, пас и ва-банк; победитель получает/теряет полную ставку;
- 🖼 Песня по картинке;
- таймеры 15+15 / 25+25 / 35+35;
- подготовка 5×5;
- серверное хранение вопросов, MP3, реверсов и картинок;
- «Мои подготовленные игры» с серверной загрузкой по идентификатору организатора;
- продолжение подготовки с другого устройства;
- дублирование и удаление игр;
- локальный тестовый стенд мешка.

## Старые игры
Игры до V47 могли не иметь `organizerKey`; новые получают `KonstantinD` автоматически. Для старых игр можно оставить прямые ссылки/локальный список, а позже сделать отдельное переназначение владельца.
