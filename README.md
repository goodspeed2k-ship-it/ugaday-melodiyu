# Угадай мелодию — V58

Постоянная ссылка: https://goodspeed2k-ship-it.github.io/ugaday-melodiyu/

## V58 — фрагмент для угадывания + музыкальная награда

Для каждой песни хранится полный MP3 и параметры:
- fragment_start — старт фрагмента для угадывания;
- fragment_duration — длительность фрагмента;
- celebration_start — старт полного трека после правильного ответа (например, припев).

Полный MP3 не обрезается. В редакторе можно проверить фрагмент и задать таймкоды. На пульте ведущего: «Фрагмент», «С начала» и «Припев».

Для старых вопросов без таймкодов используются значения по умолчанию: 0:00 и 10 секунд.

Основные механики: обычная песня, STOP, несколько игроков в команде, Песня в мешке, АПОЖ, Удвоение, Аукцион, По картинке, таймеры, серверное хранение подготовки, пульт ведущего и PWA. Финальный раунд «Песенный детектив» отложен.


## V58 — таймкоды в минутах и секундах
Для каждой песни старт фрагмента, длительность и праздничный момент задаются отдельно в формате минуты + секунды. После правильного ответа ведущий может запустить полный трек с праздничного момента.
