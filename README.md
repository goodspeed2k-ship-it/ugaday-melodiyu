# Угадай мелодию — V49

Постоянная ссылка:

## Что изменено в V49
- Исправлено отображение текущей песни на экране ведущего: название и исполнитель больше не показываются до ответа.
- Для открытой клетки отображается только тип задания: обычная песня, Песня в мешке, АПОЖ, Удвоение, Аукцион или По картинке.
- Название/исполнитель остаются доступны ведущему в редакторе и раскрываются через кнопку «Ответ».
- Все механики V47 сохранены.


## V49 — серверный список игр
- Список «Мои подготовленные игры» загружается из Supabase по organizerKey.
- Исправлена ошибка с отсутствующим `updated_at`: сортировка теперь идёт по существующему `created_at`.
- По умолчанию организатор — `KonstantinD`; тот же идентификатор используется на любом устройстве.
- Новая игра сохраняется на сервере сразу при создании.
- В подготовке изменения вопросов и загруженные MP3/АПОЖ/картинки сохраняются на сервере.
- Старые тестовые игры без organizerKey специально не возвращаются в список.
