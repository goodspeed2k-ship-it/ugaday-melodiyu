# Угадай мелодию — V54

Постоянная ссылка: https://goodspeed2k-ship-it.github.io/ugaday-melodiyu/

## V54 — PWA-пульт ведущего
- Пульт ведущего можно установить на главный экран телефона как приложение.
- В установленном режиме используется display=standalone: Chrome не показывает адресную строку и вкладки.
- После установки приложение открывается в последней сохранённой комнате ведущего.
- В пульте есть кнопка установки, если Chrome предоставляет её; иначе используется меню Chrome → «Добавить на главный экран».
- Добавлены manifest.json, sw.js и иконки приложения.
- APP_VERSION и version.json синхронизированы на 54.0.0.

## Важно
Обычная вкладка Chrome не может по желанию страницы скрыть адресную строку. Для чистого полноэкранного вида запускай установленный «Пульт ведущего» с иконки на главном экране.

## Основные механики
- Обычная песня
- Песня в мешке
- АПОЖ / реверс
- Удвоение
- Аукцион
- Песня по картинке
- Таймеры раундов
- 2–6 команд и несколько участников в команде
- STOP с серверным определением первого нажавшего
- Пульт ведущего на телефоне
- Отдельный публичный экран для ТВ
- Серверное хранение подготовленных игр
- Дублирование и удаление игр

## Финал
Отложен режим «Финальное дело / Песенный детектив» с тайными ставками, поэтапными подсказками и вводом ответов с телефонов.
