# Угадай мелодию — V53

Постоянная ссылка: https://goodspeed2k-ship-it.github.io/ugaday-melodiyu/

## V53 — пульт ведущего
- QR-код пульта ведущего генерируется прямо в браузере через встроенную QR-библиотеку, без внешнего QR-сервиса.
- QR увеличен до 360×360 с широким белым полем для более надёжного сканирования камерой телефона.
- Окно пульта открывается сверху и не уезжает за нижнюю границу экрана.
- Под QR показан короткий код игры как запасной способ открыть пульт вручную.
- Ссылка на пульт остаётся кликабельной и копируемой.
- Секретные ответы и управление остаются только на пульте ведущего.
