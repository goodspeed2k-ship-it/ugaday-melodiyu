# Угадай мелодию — V63

Постоянная ссылка: https://goodspeed2k-ship-it.github.io/ugaday-melodiyu/

## V63 — оригинал после правильного ответа

Для каждой песни хранится полный MP3, а для режима АПОЖ — отдельный реверс.

Правило воспроизведения:
- 🎵 Обычная песня: фрагмент для угадывания из оригинала → ✅ Правильно → оригинальный трек с праздничного момента.
- 🔄 АПОЖ: фрагмент для угадывания из реверса → ✅ Правильно → оригинальный трек с праздничного момента.
- 🎒 Песня в мешке: используемый для угадывания фрагмент может быть обычным/спецрежимным → ✅ Правильно → оригинальный трек с праздничного момента.
- 🖼️ По картинке: до ответа музыка не обязательна → ✅ Правильно → оригинальный трек с праздничного момента.

На пульте ведущего кнопка «🎉 Припев» оставлена для ручного запуска, но после «✅ Правильно» праздничный момент запускается автоматически.

В редакторе время задаётся в минутах и секундах, встроенный плеер позволяет выбрать позицию и записать старт фрагмента и праздничный момент.

Основные механики: обычная песня, STOP, несколько игроков в команде, Песня в мешке, АПОЖ, Удвоение, Аукцион, По картинке, таймеры, серверное хранение подготовки, пульт ведущего и PWA. Финальный раунд «Песенный детектив» отложен.


## V63
Кнопка «🎉 Припев» в пульте ведущего теперь всегда отображается; становится активной, когда для текущей песни задан праздничный момент. Запуск использует оригинальный трек с сохранённой позиции.
