## Как работает аукцион V43
1. Ведущий открывает клетку типа «Аукцион».
2. Первой обязательно ставит команда, которая открыла вопрос. Минимальная/стартовая ставка равна номиналу клетки. Если очков меньше номинала, старт всё равно возможен — команда уйдёт в минус.
3. После стартовой ставки ход передаётся сопернику с меньшим текущим счётом, затем следующему по возрастанию счёта. После этого порядок идёт по кругу, пока команды не пасуют.
4. Обычная ставка повышает текущую сумму на 100. Обычной ставкой нельзя превысить текущий счёт команды.
5. Команда может в любой момент нажать «Пас» и больше не повышать эту ставку.
6. ВА-БАНК доступен, если у команды очков больше номинала. Ставка равна всему текущему счёту команды. Если уже объявлен ВА-БАНК, обычной ставкой его перебить нельзя — нужен только больший ВА-БАНК.
7. Ведущий завершает торг. Последняя команда с наибольшей ставкой получает право ответа, песня запускается автоматически.
8. Правильный ответ: финальная ставка прибавляется к счёту ответившей команды.
9. Неправильный ответ: та же финальная ставка вычитается из счёта ответившей команды. Остальные команды за этот вопрос ничего не получают и не теряют.
10. Вся история ставок и текущий ход отображаются на экране ведущего. Игроки на телефонах видят, что идёт аукцион, но сами ставки пока фиксирует ведущий.

## 🖼️ Песня по картинке
- В подготовке клетке можно назначить тип `🖼️ По картинке` и загрузить изображение.
- При открытии такой клетки ведущий видит только изображение и не показывает название песни как заголовок.
- До правильного ответа песня не проигрывается. Кнопка `Играть` заблокирована с пометкой «Играть после ответа».
- Команды отвечают обычным STOP-механизмом. После неправильного ответа ошибившаяся команда блокируется, остальные могут нажать STOP.
- После правильного ответа стоимость начисляется команде и автоматически запускается загруженный `audio_url` как музыкальная награда.
- Для режима нужна загруженная картинка; для автоматической музыкальной награды нужен обычный MP3.


## Управление сохранёнными играми — V44
- На стартовом экране появился раздел «Мои подготовленные игры».
- Игра, открытая как ведущий, запоминается в локальном списке браузера.
- В списке можно нажать «Продолжить» и вернуться к подготовке ранее созданной игры.
- «Дублировать» создаёт новую игру с новым кодом, копирует вопросы, категории, типы, MP3, реверсы и картинки, но сбрасывает счёт, игроков, использованные клетки и состояние раундов. Это удобно для повторных мероприятий.
- «Удалить» удаляет запись игры из базы. Загруженные медиафайлы в Supabase Storage при удалении игры не обязательно удаляются автоматически и могут потребовать отдельной очистки.
- На старте также можно обновить список сохранённых игр.
